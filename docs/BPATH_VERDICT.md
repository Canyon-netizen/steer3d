## 0. 一句话

> **`w·ĥ` 这条轴，对「下一个 token 是哪个」没有解释力。**
>
> 符号维度：响应的正负由**该位置是什么 token** 决定，与对齐度无关。
> 幅度维度：`|w·ĥ|` 与 `|Δ|` 的那点相关，**完全由 token 构成**解释。
>
> 而这**不是**说 `w` 里没有信号 —— 静态读数仍然成立
> （频次加权 `w·U = +0.18424`，7/7 个 marker id 为正）。

## 1. 三条链，各自闭环

### 1.1 符号维度 —— 闭环

注入 `+w` 后 `Δ` 的**符号**由 token 组决定，两批**轨迹集合不相交**
（26 条 vs 29 条）：

| 批次 | 7196（占比最大） | 其余全部 marker | 轨迹分层 CMH |
|---|---|---|---|
| E 批次 | 121/125 = 0.968 | 2/54 = 0.037 | χ² = 53.96，p = 2.0e-13（13 层） |
| 高对齐批次 | 258/266 = 0.970 | 5/187 = 0.027 | χ² = 239.99，p ≈ 0（17 层） |

⇒ **两边符号相反**：`+w` 在占多数的 token 上恰恰是**压制**的。
⇒ `w` 只是组内加权平均，**不是**「抬高 marker 的方向」。
详见 [BPATH_MARKER_STEERING.md §4.3](BPATH_MARKER_STEERING.md)。

⚠ 批次里 `n < 10` 的 marker 组（13824 / 6771 / 80022）**不可单独判决**，
但**计入**「其余」这个整体判据 ⇒ T1 的结论不受影响。

### 1.2 幅度维度 —— 闭环，且是被**否定**地闭环

| 步骤 | 实测 | 读法 |
|---|---|---|
| A0 前提 | ρ_obs = **+0.1434**，p = 0.0402，n = 205 | 相关存在，但很小 |
| A1 两组 `\|Δ\|` 分布 | p = 0.0249（须 < 0.01） | **不过** |
| A2 换成 token 组中位数后 | ρ_null = **+0.1916**，覆盖度 **1.336** | ρ 里**没有**任何超出构成的部分 |

⇒ 把 `|Δ|` **整个换成**「它所在 token 组的中位数」后，相关**不降反升**。
⇒ `ρ_obs` 测的是**「`\|w·ĥ\|` 能否预测 token 组」**，不是对齐度效应。
⚠ A2 与 B1 **不是两条独立证据**（A1 不过 ⇒ 替换只产生一个二元信号）。
详见 §4.3c。

### 1.3 筛选本身不是中立的 —— 富集 2.28 倍

`w·ĥ > 0.1` 这个筛选，把 7196 从全体 marker 的 25.8% 拉到选中样本的
**58.7%** ⇒ **富集 2.28×**（Fisher p = 3.1e-41）。

⇒ 修订 24–33 那些「高对齐位点」**同时**是「7196 富集的位点」。
⇒ 任何「在某个筛选条件下得到的结论」都必须同时报这个富集倍数
（§4 第 10 条）。

## 3. 为什么 L7 是「不可判定」而不是「有证据反对」

这是本轮修订 43 的主要内容，也是**一次降级**。

L7 要把效应归到「概念 / 位置 / 格式」的**某一支**。B 路实测到的是：

- 响应的符号由 **token 身份**决定（§1.1）；
- 而**位置与 token 身份在这批语料里共线** —— §36.4 取数前就声明了这件事，
  §37.3 按位置三分位分层后，差异**每一层都还在**（χ² = 144.86，3 层）。

⇒ 「位置轴对照」这个动作**并没有**把位置从 token 身份里剥出来。
⇒ 观测到的差异既不能记在「位置」名下，也不能记在「token」名下。

⚠ 那 token 身份算 L7 说的「概念」还是「格式」？**本项目不判。**
marker 是 `" maybe"` / `"Wait"` / `"Let"` 这类**表层标记** ——
把「表层标记」算作「概念」还是「格式」是一个**术语决定**，不是实测能定的。
要解开它需要**按位置匹配**的采样设计（改变某个位置上放哪种 token），
那是**新的批次与新的判据**，本项目**不**去构造 —— 那会再做一次事后挑选。

⇒ 理论文档 §4 **新增第 13 条**：把效应归到「概念/位置/格式」某一支的判据，
必须先报这些支之间的可分离性；共线则判「不可判定」，不得输出支持任一支。

⚠ **措辞纪律**：阶梯的状态标签比它的 note 更容易留下越级主张。
L7 之前标的是 `evidence_against_naive_reading`，而它自己的 note 写的却是
「不能外推」—— 标签在断言一件**没测**的事。预登记 §43.1 的 L-2 就是为此写的。
