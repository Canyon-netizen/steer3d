# 原生 SwiGLU 神经元的向量干预实验

本实验研究一个固定 steering vector 如何改变真实 SwiGLU 计算，以及这些变化是否参与
造成模型输出的变化。语义目标是判断乘法算式正确性，同时独立控制自检措辞。
候选神经元在发现集选择，在不同数字的留出问题上阻断和恢复。

本轮已完成，见[测量结果与证据边界](NEURON_MEDIATION_RESULTS.md)。

实验延续 Goodfire 的原生计算单元研究思路，参考其
[Neural Networks Are Already Clean](https://already-clean.goodfire.com/) 中的符号分支和
电路验证方法。该文章是研究假说，本实验不以“所有神经元都容易解释”为前提。

## 固定实验设计

可执行的规则来源是 `experiments/neuron_mediation_v1/protocol.json`。
正式取数前已固定该文件；结果必须记录其 SHA-256，以及执行脚本、模型配置和向量哈希。
既有 B 路的剂量、P9 与判决文件保持原样；这是新的机制实验。

使用现有 B 向量 `w_L19_m0.npy`，注入 block 20 输入的最后一个位置。
本实验采用 float32、eager attention、关闭 TF32；每个分支都从同一个完整前缀重新运行，
不用 KV cache。剂量为 baseline 在该注入位置的状态范数乘 0.02、0.1、0.25，主剂量为
0.1。正负方向和四个固定随机方向共享该前缀的 baseline 标尺。
这与历史 B 路的 class_gap 定标不同，结果不能直接当作旧 P9 的重测。

固定十二对乘数，前六题用于发现，后六题用于评估。每题有四种条件：

| 算式 | 措辞 |
|---|---|
| 正确 | 普通表述 |
| 正确 | 含 Wait, let me check |
| 错误 | 普通表述 |
| 错误 | 含 Wait, let me check |

共 48 个前缀。算式真值由整数乘法独立生成，不由模型或关键词判定。
模型被要求只输出 A 或 B，表示正确或错误。主读数为正确答案字母集合与错误集合的
log probability 差；同时记录完整 softmax 后的正确答案概率、两类字母的总覆盖率、
以及实际 argmax 是否落在两类答案之外，避免仅在 A/B 条件分布上报好看的结果。

## 原生计算测量

对 block 20 到 27 的 MLP，记录最终位置的 gate 投影、SiLU 后的 gate、value 投影和
down_proj 的真实输入产品。每次采集检验产品与 gate/value 重建一致。

若 MLP 的输入为 x，则 a=SiLU(Wg x)⊙Wu x，MLP 写入为 Wd a。
因此，同一前缀两次实际前向之间的该 MLP 输出差可按原生单元分成
Σᵢ(aᵢ,steered−aᵢ,base)Wd[:,i]。x 是 MLP 真正收到的输入，包含此前的 attention 与
normalization 影响，不能直接把最初的注入向量当成 x 的变化。

汇总时还对已记录单元逐个计算 `Δa = Δs·u₀ + s₀·Δu + Δs·Δu + roundoff`，其中
`s=SiLU(g)`。三项分别表示 gate 改变、value 改变及二者共同改变在乘积中的代数项；
roundoff 单列实际 float32 产品与高精度重建的舍入差。单元图谱保留符号分支转换及
按问题等权的各项，帮助区分“gate 打开”“value 变号”和相互抵消。这是同一 MLP
输入的精确代数展开，不把三项各自称为已证明的因果路径，也不据此给单元命名。

四种 gate/value 符号组合分别计数，零因子另列。不把正输出直接等同于某个语义概念，
也不预先把负×负称为无用噪声。

每层根据发现集上 `mean(abs(Δaᵢ)) × norm(Wd[:,i])` 选择32个单元，共256个候选。
这是响应大小排序，不是语义命名。评估集的概率或正确性不参与选择。
每个候选的正负激活和实际上下文保留，供后续人工提出可证伪的功能解释。

## 阻断与恢复

阻断在注入 +v 的前向中，将候选的 product 恢复为同前缀 baseline 值。
恢复在 baseline 前向中，将候选的 product 替换为同前缀 +v 值。
同时执行每层单独替换和全部八层联合替换；后续计算在接收分支内重新运行。
只改最后一个位置的指定 product 坐标。

四组随机单元在相同层取相同数量，并按发现集激活大小和 down_proj 列范数的四分位
进行匹配。候选不进入随机组。若相同分箱不够，使用最近分箱并报告回退次数。
在每一层，将随机 product 位移缩放到候选替换实际产生的残差写入范数；记录缩放前后
范数和缩放系数。实际匹配误差超过 0.5% 或缩放超过冻结上限就失败，不静默删掉该格。
这类随机替换可能离开自然激活分布；幅度相等不能消除所有对照差异。

以主读数 score 表示：向量总效应为 score(+v)−score(base)，阻断效应为
score(+v)−score(block)，恢复效应为 score(restore)−score(base)。
这三项分别报告，不把它们加成“解释百分比”。多个层之间会相互作用。

## AIME 上的迁移

固定使用原 B 批 p06 到 p11 的两种模式。沿用原 R6 的 marker 抽样器，每条轨迹取
前缀不超过2048个 token 的前两个抽样位置；无合格位置则报告，不挑替代位置。
只读取 NPZ 头和小型 token_ids，不加载整个 hidden_states 数组。

从原始侧车和原 R6 抽样函数独立生成的 `source_manifest.json` 固定了预期迁移位置及
来源哈希。12条轨迹共18个合格位置，距每条最多两个位置的上限少6个；这6个缺口均为
某条轨迹只有一个抽样位置落在长度界限内，不补选其他位置。结果汇总前逐一检查位置、
marker、前缀长度、来源文件与抽样代码哈希，缺格或替换位置均使审计失败。

候选神经元完全沿用乘法发现集，不在 AIME 上重新排序。测量完整 softmax 后 marker
集合的 logprob、原始 LSE，以及联合阻断、恢复和四个匹配随机对照。
这里检验的是线路迁移，不是答案正确性。原向量可能与 AIME 采集来源有重叠，不能把
这些位置称为“向量提取之外的独立测试”。

## 测量与报告要求

正式结果包括全部48个固定前缀、全部固定剂量和随机方向，以及所有合格的 AIME 前缀。
不筛掉效应方向不合预期的案例。先在同一问题内平均真值与措辞条件，再按问题等权
汇总；报告问题数、每题效应和范围，不把多个 token 或随机方向当成独立问题。
本轮不根据探索结果追加显著性门槛。

运行前检验向量与协议身份、未挂钩与采集 baseline 一致、零注入一致、baseline 与
steered 两个世界的 identity donor patch 一致。小型已知网络测试实际坐标、异常清理、
正负分支和匹配范数。结果只有在所有固定格完成后才能标 complete。

“某组原生单元参与了给定前缀下的向量效应”仍不是“已经理解了通用自检算法”。
若要命名为推理功能，后续还需要给出上下游读取路径及对新反例的预测。
