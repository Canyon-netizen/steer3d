# 通用向量理论在 B 路上的机制检验

本轮得到的是一条可复算的解释链：向量注入 → 后续状态变换 → RMSNorm → token
分数 → 完整 softmax 概率。它解释了为什么静态 `w·U` 会误判某些实际响应。
它尚未把 B 向量识别为“自检”“正确性”或某一种推理算法。

理论主体见 [VECTOR_FUNCTION_THEORY.md](VECTOR_FUNCTION_THEORY.md)。这里给出其数值
机制部分的新测量、历史结论的适用范围，以及语义机制仍缺的识别条件。

## 可以通用的理论命题

一个向量的功能依赖模型权重、注入位置、完整状态、剂量与执行策略。对任意方向，
都可以定义它诱导的干预算子及其对完整行为分布的影响；这提供统一的解释对象。
要得到人可以理解的推理功能，还需要一个由任务操作定义的抽象状态 `τ(S)`。

**高层操作存在定理。** 给定抽象 `τ`，存在确定的向量功能操作 `Eᵥ,α`，使

\[
\tau(I_{v,\alpha}(S))=E_{v,\alpha}(\tau(S)),
\]

当且仅当在声明域上

\[
\tau(S_1)=\tau(S_2)\Rightarrow
\tau(I_{v,\alpha}(S_1))=\tau(I_{v,\alpha}(S_2)).
\]

必要性来自同一个高层状态不能被确定操作送往两个不同状态；充分性来自用任意
低层代表定义 `E(z)=τ(I(S))`，上述条件保证定义与代表选择无关。
再验证每一步模型转换满足 `τ∘F=P∘τ`，就能由可解释程序 `P` 预测干预后计算。
有限、确定性、对操作闭合的状态系统，可以从独立语义读出出发不断细分状态类，
构造保留读出的最粗稳定抽象；原理论文档给出证明和近似误差界。
这个命题的通用性不依赖某个向量的名字。

这里的语义变量不能用“`v·h` 高就是谨慎”来定义，否则解释仍在循环。
应先规定一个有独立意义的操作，例如候选约束的验证结果及据此改变的决策规则，
再识别模型实际承载它的状态和转换。用互换干预核验低层与高层变量对应的研究基础
见 [Causal Abstractions of Neural Networks](https://arxiv.org/abs/2106.02997)。

仅凭向量数值配一个跨模型的固定语义功能，不可能成立：两个标量模型的同一行为
概率分别为 `σ(h)` 和 `σ(−h)`，同一个 `v=+1` 对它们作用相反。固定模型也不够：
`p=σ(h²)` 在正、负状态上的局部响应相反。这个反例排除的是“只依赖 v 的语义映射”，
没有排除模型、状态和领域条件下的机制解释。

## 本轮测量的边界与坐标

- 模型：本地缓存的 Qwen3-1.7B，28 blocks，2048 维；前向使用 bfloat16。
- 向量：`w_L19_m0.npy`，SHA-256
  `6ef6df33e2cb22d647594d7d9f0b371e7bec8c9a0cd25741095b7fe26a890c16`。
- 固定剂量从历史执行代码 `dose_sweep.py.DOSE` 导入：0.02、0.05、0.1、0.25、0.5、1。
  `α=rel×231.97767639160156`。随机单位方向使用 R6 同一 seed=42。
- 取生成位置 `t` 的同一前缀 `prompt + generated[:t]`，在 block 20 输入的最后一个
  位置注入；实际改动的是 `P+t−1`，对应记录中的 `NPZ[t−1,19]`。
  B 向量的训练位置规则为 `pos_offset=0`，即 marker 时刻的 H[t]；不能把提取规则
  与本次在 marker 之前的注入位置混为一谈。
- 四条固定轨迹按 R6 的非空分位抽样规则，共 19 个位置。每个位置测试
  `+w / −w / rand` 各六档，共 342 次非零干预；基线复跑逐位一致。
- 在四条轨迹的首位置，沿原层阶梯做 40 次注入层扫描；最终 norm 输出后为校准点。
  校准使用实际浮点状态增量 `δh`，检验 `Uδh` 与输出增量的数值误差界，四处均通过。
- 独立补充扫描在同样四个首位置增加 norm 输入读取，共 72 次。
  每一次的原始集合分数和集合 logprob 与前一批完全一致；RMSNorm 状态重建全部通过
  保守的 bfloat16 舍入和 float32 累加误差界。

固定剂量、位置与原判据未因新结果调整。新增扫描是机制测量，不是重新筛选 P9 的样本。

## 数值作用为什么发生

固定前缀，令 `Fℓ` 为注入点到最终 norm 输入的真实下游计算，`N` 为最终 RMSNorm，
`U` 为 lm_head，`z` 为 logits。理想实数计算满足

\[
z_\alpha=U N(F_\ell(h+\alpha v)),\qquad
\Delta\log p_j=(z_{\alpha,j}-z_{0,j})
 -[\operatorname{LSE}(z_\alpha)-\operatorname{LSE}(z_0)].
\]

对 marker 集合 `G`，正确的读数是

\[
\Delta\log P(G)=\Delta\operatorname{LSE}(z_G)
 -\Delta\operatorname{LSE}(z).
\]

原始集合 LSE 没有第二项，因此符号可能和概率变化相反。
“某些 marker 的 `U_j·v` 为正”既没有包含 `Fℓ` 和 `N`，也没有减去词表竞争项。
它不能保证从 block 20 注入时集合概率的符号、排序或幅度。

在可微实数近似下，任意向量的局部机制由真实模型导数给出：

\[
\frac{d\log p_j}{d\alpha}
=(U_j-\mathbb E_{k\sim p_\alpha}U_k)
 J_N\,J_{F_\ell}\,v.
\]

集合读出将第一项换成 `E[U|G]`。有限剂量的效果是沿干预路径积分；不能只把
baseline 的导数乘一个很大的 α。这个公式解释的是实际权重和状态为何产生数值作用。
它没有把 token 概率变化自动命名为某一种推理功能。浮点量化和 greedy 的跳变用
实际有限前向读数处理，本轮没有把最小剂量当成零点导数。

RMSNorm 为 `N(h)=γ⊙h/r(h)`，其中 `r(h)=√(mean(h²)+ε)`。
对 norm 前两个状态 `h₀,h₁`，有精确有限分解

\[
N(h_1)-N(h_0)=
\underbrace{\gamma\odot(h_1-h_0)/r_1}_{\text{前传项}}
+\underbrace{\gamma\odot h_0(1/r_1-1/r_0)}_{\text{重缩放项}}.
\]

RMSNorm 的尺度归一化机制见原论文
[Root Mean Square Layer Normalization](https://arxiv.org/abs/1910.07467)；上式是针对两个
干预状态的直接代数分解。它揭示同一次干预会同时传递状态差，并重缩放原有状态。
这些项由被测模型的实际 γ 和状态计算，未拟合一个人为的“功能矩阵”。

## 新数据：传播大小与方向是两件事

下面固定 `+w, rel=1`。block 范数增益为 norm 前位移范数除以实际注入位移范数；
RMSNorm 范数增益为 norm 后位移范数除以 norm 前位移范数。余弦相对于注入方向。

| 轨迹首位置 | block 范数增益 | RMSNorm 范数增益 | norm 后余弦 | raw ΔLSE | 集合 Δlogprob |
|---|---:|---:|---:|---:|---:|
| p00 think，t=204 | 2.1653 | 0.06522 | 0.3655 | −0.750000 | +0.017536 |
| p00 no_think，t=252 | 2.1032 | 0.03360 | 0.4214 | +1.250002 | +0.030019 |
| p01 think，t=518 | 3.2482 | 0.06596 | 0.3027 | −2.748640 | +0.022979 |
| p01 no_think，t=422 | 2.0383 | 0.03490 | 0.4352 | +1.000002 | +0.001488 |

因此，这四处的后续 block 扩大位移范数，最终 RMSNorm 缩小它，方向也发生明显变化。
范数增益不是目标 token 的增益，更不是“自检功能由哪个模块贡献百分之多少”。
该结论覆盖这四个位置和此剂量，不能外推成所有前缀上的固定增益。

一个更细的数值机制出现在 p01 think 的 t=518：baseline 概率最高的 marker 是
`" maybe" / 7196`。在理想 RMSNorm 的分解中，投影到其 U 行的前传项为 +2.033406，
重缩放项为 −4.743288，合计 −2.709883；实际 norm 后位移读出为 −2.726447，
实际浮点 raw logit 变化为 −2.75。状态重建误差在已声明的保守数值界内。
重缩放项抵消并超过前传项，解释了这个 token 原始分数的下降。

但此处完整词表的 LSE 下降 −2.771619，比 marker 集合的 −2.748640 更多。
所以集合 Δlogprob 为 +0.022979，概率从约 0.77542 增至 0.79344。
原始分数变低与概率变高同时成立，不应选其中一个读数命名“自检减少/增加”。
当前范围内也存在位置差异：同一 p01 think、同一 `+w, rel=1` 在 t=7986 的
raw ΔLSE 为 +4.499996，集合 Δlogprob 为 +0.450740。

## “43 倍衰减”的适用范围更正

历史 42.7 来自 B 向量的 `class_gap×语料频次加权 U·w`。语料频次不是当前前缀
的集合 softmax 权重，因此它不是该位置的 LSE 一阶预测。历史
`layer_sweep_t1.json` 则使用已经被取代的 `w_t1`，gap≈172.4178；其中 `the` 的校准
也属于这个旧向量。不能把这份层剖面与 B 的 42.7 拼成一个测得的“八层衰减43倍”。

新的 B 扫描中，norm 输出之后注入的 raw 集合增量为 41.00–41.75，block 20 输入
注入的四个增量为 −0.75、+1.25、−2.74864、+1.00。两处 no_think 的前后比较量级约
32.8 和 41.25，但这是两个不同注入位置的有限效应比值，包含 block、RMSNorm 和
状态条件，仍不能命名为仅由八个 block 产生的局部导数增益。
新的同向量层剖面也不单调：不能再声称“越早注入效应必然越大”。

## 判决与交互交付

原 P9 仍为 1/3；本轮不改变并列边界、剂量、方向、抽样或通关要求。
按原流程不发布 R6 的 P6/P7/P8 主判决。新集合 logprob 不能偷偷替换 P9 的历史
raw LSE 指标。原 dose 的 D1/D2 呈混合形态，D3 失败；独立审计确认两条 no_think
的 D4 单调正控通过。历史 D4 实现先筛选单调轨迹再检查单调，不能拒绝坏正控；
新审计同时拒绝非单调与缺失正控，并保留原实现作为对照。

网页 `/bpath-explorer` 展示 19 个实际位置的完整剂量读数、七个逐 id token、
同向量层扫描、2D/3D 状态位移，以及四个首位置的 RMSNorm 分解。
3D 使用每层共享 PCA 基绘制实际状态增量，baseline 为原点；坐标轴没有语义名称。
末层三维覆盖约 62.9% 的位移方差，完整状态效应不能由这三个坐标代替。
点选 token 可切换剂量与层读数；位置、方向、剂量和状态读取层可独立选择。

原始数据与来源哈希在 `.cache/bpath/results_B/`；网页构建器是
`scripts/build_bpath_explorer.py`。补充执行脚本与固定协议位于 `.cache/bpath/`。
构建器交叉检查历史 R6 常量、原 P9、向量 SHA、剂量、每个位置的 18 个变体、校准点
和独立 RMSNorm 批的响应一致性。全量生成审计 `bpath_completion_audit.json` 确认
固定 60 题 × 两个模式的 120/120 轨迹，包括形状、token 轴、题目、模型身份和标签。
校准自检在四个真实位置上同时验证“测得响应通过、反号预测拒绝、零注入拒绝”；
D4 自检验证干净正控通过，非单调和缺失正控拒绝。

这些新结果建立了数值因果链，尚未建立满足前述抽象定理的可解释推理程序。
在冻结且有独立语义的程序上识别 τ、验证干预闭合及模型转换对应之前，
给 B 向量一个通用“自检功能”名称仍没有理论与实验证据。
