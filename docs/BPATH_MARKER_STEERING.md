## 0. 一句话

> **`w·U[marker] > 0` 是纯静态读数，一次前向都不用；
> 「注入后剂量响应稳定、单调、符号正确」必须真跑模型、逐位置、逐剂量地测。
> 前者成立不蕴含后者。**
>
> 反例（本项目实测）：同一个 `w`、同一个模型，`w·U` 对 7 个 marker id **全部为正**、
> 频次加权 **+0.184**（相对随机基线 **7×**）；在 `no_think` 轨迹上剂量响应
> **2/2 轨迹 × 2 个方向全部单调**；在 `think` 轨迹上 **0/2 轨迹 × 2 个方向全部非单调**。

## 1. 为什么要把这两级分开

既有八级证据阶梯里，这两件事落在不同级、且 `needs` 完全不同：

| 级 | 主张 | `needs` | 仪器 |
|---|---|---|---|
| **L2** | 这个方向线性编码了观测量 y | 留出轨迹 + 打乱地板 | **静态**：一次前向 |
| **L4** | 能写成可注入的 `diff_of_means` | 留一轨迹上配方仍预测得动 | **静态**：算投影 |
| **L6** | 注入改变行为，且改变是这条方向特有的 | 教师强制前向 + **随机方向臂** | **干预**：真跑模型 |
| **L7** | 改变的是这个**概念**，不是位置或格式 | 行为指标 + **位置轴对照** | **干预**：逐位置 |

**L2/L4 是「可读性」，L6/L7 是「可控性」。** 中间隔着的不只是工作量，
是**两个不同的物理过程**：一个是「这个方向与观测量相关」，
另一个是「把它写进残差流，模型行为真的随之改变，且改变不是别的东西造成的」。

⚠ 把 L2 的绿当成 L6 的绿，是本领域最常见的一种越级。
本项目的定量反例见 §3。

## 2. 三条实测约束（都可复算）

### 2.1 一阶预测被下游 block 高估约 43 倍

在 `model.norm` **输出之后、`lm_head` 之前**注入时，下游是恒等映射，
`Δlogit = α·(w·lm_head[token])` **精确成立**（不是近似）：

```
预测 = class_gap 231.978 × 频次加权点积 0.18424 ≈ +42.7
实测（L=20 注入）                              = +1.0
```

同一批数据里 `' the '` 的预测 **−5.7944** / 实测 **−5.7969、−5.7891、−5.8047**
**逐位吻合** ⇒ 钩子、公式、归一化口径都没错，差的正是下游 8 层。

层扫描给出同一机制的直接证据（同一个向量换层注入，效应跨两个数量级）：

| 注入层 | L=0 | L=4 | L=12 | L=20 | L=24 | L=27 |
|---|---|---|---|---|---|---|
| Δmarker | −32.7 | −28.0 | −29.5 | **−1.25** | −0.25 | +0.5 |

> **⇒ `w·U[marker]` 是可靠的「符号与相对排序」指标，
> 但绝不是效应幅度的预测器。两者之间隔着一个未建模的下游增益 `G`。**

### 2.2 算术均值会掩盖符号分裂

`w·U[marker]` 的**算术均值**是粗指标。某条 `w` 的算术均值 **+0.0317**（看着是正的），
逐 id 看却是：

| marker id | 语料占比 | `w·U` |
|---|---|---|
| 7196 | 25.1% | +0.156 |
| 13824 | 21.1% | **−0.013** |
| 10061 | 20.7% | **−0.007** |

而 P9 读的是 `lse(logits[MARKER_IDS])`，其一阶近似是
`Σ_j p_j · α · (w·U[j])` —— **起决定作用的是当前概率最高的那一个**，不是七个的均值。

> **⇒ 报告 token 级主张时必须逐 id + 词频，不能只报均值。**

### 2.3 「推理正确」不等于「结果变好」

为了让训练点与注入点同空间，把训练位置从 `H[t]`（marker 自身）改成 `H[t-1]`
（注入点）在**逻辑上完全正确**。实测：

| 训练位置 | 频次加权 `w·U` | 全正 id |
|---|---|---|
| `H[t]` | **+0.1842** | **7/7** |
| `H[t-1]` | +0.0286 | 4/7（且两个高频 id 为负） |

「坐标系对齐」是**必要条件，不是充分条件**。同空间里训出来的方向，
还得**恰好指向目标 token**——这是另一件事。

## 3. 对 L7 最直接的证据：位置轴对照的结果是「不能外推」

阶梯里 L7 的 `needs` 写着「**位置轴对照**」。本项目做了一次：

同一条 `w`，剂量阶梯 `[0.02, 0.05, 0.1, 0.25, 0.5, 1.0]`（取数前写死，一个字未改），
逐剂量中位：

| 轨迹 | `w+` 逐剂量 | `w−` 逐剂量 | 形态 |
|---|---|---|---|
| `p00__no_think` | 0.0 → 1.1251 | … → −6.375 | **单调** |
| `p01__no_think` | 0.0625 → 0.8765 | −0.0625 → −2.6875 | **单调** |
| `p00__think` | **+0.125 → +0.25 → +0.25** → −0.1248 | 噪声 → **−5.625** | 小剂量正向、峰后转负 |
| `p01__think` | **−0.25 → −0.25 → −0.375** → −2.5814 | 噪声 → −0.125 | **最小剂量即负** |

**汇总：`no_think` 上 `w+`/`w−` 各 2/2 轨迹单调；`think` 上各 0/2 轨迹单调。**

两条 `think` 轨迹给出**相反**的形态 ⇒「方向问题 vs 量纲问题」这个二分**不成立**，
真正的模式是**效应的符号与幅度都强烈依赖具体位置与轨迹**。

> **⇒ 位置轴对照不是 L7 的补充验证，而是 L6 结论能否外推的生死判据。**
> 不做这一轴，「注入能改变行为」这句话在别的轨迹上可能直接反号。

## 4. 写进判据的建议（**不是**改既有判据，是新增一条约束）

在任何「steering 向量编码了概念 X」的断言上，加一条**可判定的检查**：

> **可读性-可控性分离检查**
> 1. 报 `w·U[target]`（静态）时，**必须**同时报逐 id 符号与语料频次；
> 2. 声称「可控」时，**必须**给逐剂量中位曲线，且**至少两个位置**、
>    含**一个同范数随机方向臂**；
> 3. 出现「同一方向在不同位置形态相反」时，**禁止**用单一轨迹的曲线
>    支撑任何机制性主张——先报位置依赖。

本项目第 3 条是**实测触发**的（两条 `think` 轨迹相反形态），
不是假想防御。
