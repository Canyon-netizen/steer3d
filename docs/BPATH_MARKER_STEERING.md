## 0. 一句话

> **`w·U[marker] > 0` 是纯静态读数，一次前向都不用；
> 「注入后剂量响应稳定、单调、符号正确」必须真跑模型、逐位置、逐剂量地测。
> 前者成立不蕴含后者。**
>
> 反例（本项目实测）：同一个 `w`、同一个模型，`w·U` 对 7 个 marker id **全部为正**、
> 频次加权 **+0.184**（相对随机基线 **7×**）；在 `no_think` 轨迹上剂量响应
> **2/2 轨迹 × 2 个方向全部单调**；在 `think` 轨迹上 **0/2 轨迹 × 2 个方向全部非单调**。

> **最干净的一例（§4.3，修订 37）**：上面那句「`w·U` 对 7 个 marker **全部为正**」，
> 和「注入 `+w` 之后，占比最大的 marker 7196 有 **97% 的位点被压制**」
> **同时成立**（两批共 632 个位点、55 条不相交的轨迹）。
> ⇒ 静态读数对**每一个** token 都为正，行为响应却对**其中一个**最强且**符号相反**。
> 这不是装置故障，是「类差分 = 组内平均」这条默认假设本身的裂缝。

## 1. 为什么要把这两级分开

既有八级证据阶梯里，这两件事落在不同级、且 `needs` 完全不同：

| 级 | 主张 | `needs` | 仪器 |
|---|---|---|---|
| **L2** | 这个方向线性编码了观测量 y | 留出轨迹 + 打乱地板 | **静态**：一次前向 |
| **L4** | 能写成可注入的 `diff_of_means` | 留一轨迹上配方仍预测得动 | **静态**：算投影 |
| **L6** | 注入改变行为，且改变是这条方向特有的 | 教师强制前向 + **随机方向臂** | **干预**：真跑模型 |
| **L7** | 改变的是这个**概念**，不是位置或格式 | 行为指标 + **位置轴对照** | **干预**：逐位置 |

**L2/L4 是「可读性」，L6/L7 是「可控性」。** 中间隔着的不只是工作量，
是**两个不同的物理过程**：一个是「这个方向与观测量相关」，
另一个是「把它写进残差流，模型行为真的随之改变，且改变不是别的东西造成的」。

⚠ 把 L2 的绿当成 L6 的绿，是本领域最常见的一种越级。
本项目的定量反例见 §3。

## 2. 三条实测约束（都可复算）

### 2.1 一阶预测在注入点处精确成立，移出注入点即掉进噪声

> ⚠ **本节做过一次披露式更正（预登记修订 14）。**
> 初版标题是「一阶预测被下游 block 高估约 43 倍」，**该结论已撤回**。
> 撤回理由见本节末与预登记 §14.1：那个 43 倍是把校准点自己的残差
> 与 L=20 的残差混着比得来的，且**跳过了符号为负**这件事。

在 `model.norm` **输出之后、`lm_head` 之前**注入时，下游是恒等映射，
`Δlogit = α·(w·lm_head[token])` **精确成立**（不是近似）。
用选中臂 B（`w_L19_m0.npy`，`α = 231.978`，`w·U = +0.180199`）实测：

```
预测 α·(w·U)  = +41.8022
实测（L=−1 校准点） think +41.2500  ratio 0.9868
                     no_think +41.0000  ratio 0.9808
```

⇒ 钩子、公式、归一化口径、坐标系**都对**。

但**把注入点移到任何一个 block 上，读数立刻掉进噪声**：

| 注入层 | L=0 | L=4 | L=8 | L=12 | L=16 | L=20 | L=24 | L=26 | L=27 |
|---|---|---|---|---|---|---|---|---|---|
| Δmarker (think) | +1.00 | −1.49 | +0.54 | +3.50 | +1.27 | −0.75 | 0.00 | +0.75 | +1.00 |
| Δmarker (no_think) | 0.00 | −2.60 | −3.92 | 0.00 | +0.25 | +1.25 | +0.50 | +0.50 | −0.25 |

`|ratio|`（实测 ÷ 预测）在 `L=0…27` 落在 **0.0000–0.0939**，
且 **think 逐层变号 4/8 次**、`L=20` 处 think 与 no_think **异号**。

> **⇒ 不存在「一个衰减倍数」。** 硬取单点会得到三个互不相等的数
> （臂 B think 0.0179 / 臂 B no_think 0.0299 / 臂 A 0.2285，即 17.9 / 29.9 / 228.5 倍），
> 预登记 E4 判这属于**未定义**，不受理。
>
> **`w·U[marker]` 的正确用法是：在校准点读它** ——
> 它给出该方向在 unembedding 空间里指向什么；
> **在中间层注入后读到的量，与它没有可预测的定量关系。**
> 这比「幅度算不准」更强：不是精度问题，是**掉进噪声**。

### 2.2 算术均值会掩盖符号分裂

`w·U[marker]` 的**算术均值**是粗指标。某条 `w` 的算术均值 **+0.0317**（看着是正的），
逐 id 看却是：

| marker id | 语料占比 | `w·U` |
|---|---|---|
| 7196 | 25.1% | +0.156 |
| 13824 | 21.1% | **−0.013** |
| 10061 | 20.7% | **−0.007** |

而 P9 读的是 `lse(logits[MARKER_IDS])`，其一阶近似是
`Σ_j p_j · α · (w·U[j])` —— **起决定作用的是当前概率最高的那一个**，不是七个的均值。

> **⇒ 报告 token 级主张时必须逐 id + 词频，不能只报均值。**

### 2.3 「推理正确」不等于「结果变好」

为了让训练点与注入点同空间，把训练位置从 `H[t]`（marker 自身）改成 `H[t-1]`
（注入点）在**逻辑上完全正确**。实测：

| 训练位置 | 频次加权 `w·U` | 全正 id |
|---|---|---|
| `H[t]` | **+0.1842** | **7/7** |
| `H[t-1]` | +0.0286 | 4/7（且两个高频 id 为负） |

「坐标系对齐」是**必要条件，不是充分条件**。同空间里训出来的方向，
还得**恰好指向目标 token**——这是另一件事。

## 3. 对 L7 最直接的证据：位置轴对照的结果是「不能外推」

阶梯里 L7 的 `needs` 写着「**位置轴对照**」。本项目做了一次：

同一条 `w`，剂量阶梯 `[0.02, 0.05, 0.1, 0.25, 0.5, 1.0]`（取数前写死，一个字未改），
逐剂量中位：

| 轨迹 | `w+` 逐剂量 | `w−` 逐剂量 | 形态 |
|---|---|---|---|
| `p00__no_think` | 0.0 → 1.1251 | … → −6.375 | **单调** |
| `p01__no_think` | 0.0625 → 0.8765 | −0.0625 → −2.6875 | **单调** |
| `p00__think` | **+0.125 → +0.25 → +0.25** → −0.1248 | 噪声 → **−5.625** | 小剂量正向、峰后转负 |
| `p01__think` | **−0.25 → −0.25 → −0.375** → −2.5814 | 噪声 → −0.125 | **最小剂量即负** |

**汇总：`no_think` 上 `w+`/`w−` 各 2/2 轨迹单调；`think` 上各 0/2 轨迹单调。**

两条 `think` 轨迹给出**相反**的形态 ⇒「方向问题 vs 量纲问题」这个二分**不成立**，
真正的模式是**效应的符号与幅度都强烈依赖具体位置与轨迹**。

> **⇒ 位置轴对照不是 L7 的补充验证，而是 L6 结论能否外推的生死判据。**
> 不做这一轴，「注入能改变行为」这句话在别的轨迹上可能直接反号。

## 4. 写进判据的建议（**不是**改既有判据，是新增一条约束）

在任何「steering 向量编码了概念 X」的断言上，加一条**可判定的检查**：

> **可读性-可控性分离检查**
> 1. 报 `w·U[target]`（静态）时，**必须**同时报逐 id 符号与语料频次；
> 2. 声称「可控」时，**必须**给逐剂量中位曲线，且**至少两个位置**、
>    含**一个同范数随机方向臂**；
> 3. 出现「同一方向在不同位置形态相反」时，**禁止**用单一轨迹的曲线
>    支撑任何机制性主张——先报位置依赖。
> 4. 声称「`w` 与该处激活对齐得越好、注入越有效」这类**剂量-有效性**关系时，
>    **必须**按 `w·ĥ` 的符号/量级**分组**报 `Δ` 的中位与符号率，
>    **并且必须**报同范数随机方向在**同一批位点**上的幅度对照
>    （`n_ctrl_ge`）；`n < 8` 的组**只作描述、不作判决**。
> 5. 任何**阈值**（噪声地板、筛选分位、纳入边界）**必须与被判数据同一口径**
>    —— 同剂量档、同 mode 切片。阈值若取自另一个切片，它就是在替
>    **另一个分布**做决定，而报告里看不出来。
> 6. 任何「**例外数 ≤ k**」形式的判据，**必须报 `n_judge`（可判样本数）**，
>    且在 `n_judge ≤ k+1` 时**直接判「无法判定」**，不许输出 PASS。
>    理由：`n_judge ≤ k+1` ⇒ 例外数最多 `k+1` ⇒ **恒 ≤ k** ⇒
>    该判据对**任何**数据都通过。单个样本的判据不是判据。
> 7. **多个筛选/门槛相乘时，必须算一遍联合通过率。**
>    逐条看每道门都「有理由」，乘起来可能把样本压到判据失效。
> 8. 任何「`w` 编码了概念 X」的断言，**必须报组内逐 token 的响应符号**。
>    若符号**分裂**，`w` 只能读作「对该 token 集合的**加权平均**」，
>    **禁止**表述为「把 X 抬起来」。理由：一个对照类差分是**组内平均**；
>    组内响应符号不一致时，这个平均**不代表任何单个 token**，
>    它的效应量也被**占多数的 token** 主导。

本项目第 3 条是**实测触发**的（两条 `think` 轨迹相反形态），
第 4 条是**实测触发**的（假设 H「有效剂量 ≈ α·(w·ĥ)/‖h‖」被证伪：
`w·ĥ>0` 的 20 个超地板位点 **20/20 全为负**，而 `w·ĥ≈0` 的 100 个中位为正），
第 5 条也是**实测触发**的（噪声地板误把三档剂量混在一起取，
使 `w·ĥ<0` 组多出一个**对照臂动得更多**的位点）。
第 6、7 条同样是**实测触发**的 —— 见下 §4.2，那次它们同时生效。
第 8 条也是 —— 见下 §4.3。
这六条都不是假想防御。
这五条都不是假想防御。

### 4.2 一次「判据无牙齿」的实测（修订 33，E 批次）

极对齐端批次：26 条新轨迹 / 179 个位点（**逐轨迹最高十分位 ∩ `|w·ĥ|>0.1`**，
绝对边界是修订 32 加的；没有它的话，那 221 个里有 42 个 `|w·ĥ|<0.1`，
相对该轨迹极端但绝对上不是高对齐位点），1100 次前向。判据阈值在取数前写死，
判定时**一个都没动**。

| 判据 | 实测 | 判定 |
|---|---|---|
| **E1** 方向 | 同号率 **0.344**（31/90），须 < 0.25；Fisher 双尾 p = 0.0495 | **不过** |
| **E2** 逐轨迹 | 可判 **1** 条 / 不判 **25** 条 | **无法判定**（无牙齿） |
| **E3′** 对照 | `ctrl_ge` 3/90 = 0.033；p95 比 **1.0003** | **过** |

**⇒ 极对齐端的方向性主张不成立。** 那个「Δ 与 `w·U` 反向」的主张，
在带绝对边界的样本上**不成立**（E1 不过）。
E3′ 过**不能**被读成「三项里过了两项」—— 它是**对照健全性**检查，
一个「测得干净但方向相反」的结论，E3′ 恰恰会通过。

**E2 那一栏暴露的是判据缺陷，不是数据结论。** 判定器原始输出是「通过」，
但可判轨迹只有 **1** 条，而例外数上限是 1 条 ⇒ 例外数最多 1 ⇒
**该判据对任何数据都返回 PASS**。唯一那条可判轨迹
（`aime__aime26__p18__think`，8 个位点、8 个负向）即便**全部变成正向**，
照样打「通过」。⇒ 如实判**「无法判定」**：
报「通过」就是**测了但没测到**，比失败更糟。

**为什么会只剩 1 条**（第 7 条）：噪声地板 1.4996 把 179 个位点砍到 90 个
（**50%**），再叠上「每条轨迹 ≥8 个**超地板**位点」的可判门槛
—— 两道门各自都有理由，**相乘**就把样本压到判据失效。
各轨迹超地板位点数的中位数只有 **3**。

处置已落成代码：`extreme_verdict.py` 现在在 `n_judge ≤ max_exc+1` 时
**强制判「无法判定」**，并输出 `teeth_ok` 字段标记该状态；
先验里用**相反的两种数据**（主轨迹全负 / 全正）验证判据给出**同一个**
「无法判定」，另配 `n_judge=2` 仍不可判、`n_judge=3` 能判失败的用例，
确保守卫**没有过度拦截**。

**判决之外的形状（同屏印出，不用于推翻判定）**：超地板的 90 个位点按
`|w·ĥ|` 四分位，同号率 0.273 → 0.217 → 0.364 → **0.522**，
Δ 中位 −1.500 → −1.750 → −1.749 → **+1.500**。

⚠⚠ **但逐档对「无方向性」零假设做过检验之后，这个形状不能当线索**
（修订 35 的更正）：

| 分位 | n | 同号率 | Δ 中位 | vs 50% 的双尾 p |
|---|---|---|---|---|
| Q1（最低） | 22 | 0.273 | −1.500 | 0.052 |
| Q2 | 23 | 0.217 | −1.750 | 0.011 |
| Q3 | 22 | 0.364 | −1.749 | 0.286 |
| **Q4（最高）** | 23 | 0.522 | **+1.500** | **1.000** |

**Q4 的 0.522 与掷硬币完全不可区分（p = 1.000）** ——
「Δ 中位转正」**不是**「极对齐端同向」的证据，它与「没有方向」同样兼容。

唯一剩下的一点是档间对比：Q4（12/23 = 0.522）vs Q1–Q3 合并（19/67 = 0.284），
Fisher 双尾 OR = 2.756、p = 0.046。但这 4 档是**事后**切的，
纯噪声下也有约 **19%** 的概率在某档上冒出 p ≤ 0.05
⇒ 最多算「新数据上再看一眼」的弱线索，**不构成证据**。

⇒ 「越对齐越反向」这条线在极对齐端**没有得到支持** ——
但成立的理由**不是**「Q4 反向」，而是**四档全都没给出任何可判的方向性证据**
（E1 不过、E2 无法判定）。

### 4.3 `w` **不是** token 无关的「抬高 marker」方向（修订 37）

判据在**取数前**写死（预登记 §36.4，按轨迹分层的 CMH，`p < 0.01`），
样本量守卫同批写死。两批**轨迹集合不相交**：

| marker id | 文本 | E 批次（26 条 / 179 位点）负向 | 高对齐批次（29 条 / 453 位点）负向 |
|---|---|---|---|
| **7196** | *" maybe"* | **121/125 = 0.968** | **258/266 = 0.970** |
| 14190 | *"Wait"* | 0/29 = 0.000 | 0/117 = 0.000 |
| 10061 | *"Let"* | 2/15 = 0.133 | 1/46 = 0.022 |
| 13824 | *" Wait"* | 0/6 = 0.000 | 0/6 = 0.000 |
| 6771 | *" Let"* | 0/4 = 0.000 | 1/9 = 0.111 |
| 80022 | *"Hmm"* | — | 3/9 = 0.333 |

⇒ **注入 `+w` 会压制占比最大的 marker（7196，97% 负向），
同时抬高其余全部 marker（97% 正向）。两边符号相反。**

分层 CMH：E 批次 χ² = 53.96、p = 2.0e-13（13 层）；
高对齐批次 χ² = 239.99、p ≈ 0（17 层）。两批都过 0.01 的阈值。

**位置这一项查了，不是它**（补充分析，非预登记判决）：按位置三分位分层，
7196 的负向率是 0.978 / 0.957 / 0.970，**每一层都几乎一样**；
按位置分层的 CMH χ² = 144.86、p ≈ 0。

⚠ **仍然不说「由 token 身份造成」** —— 这是观察数据，位置与 token 在这批
语料里共线。要拿因果需要**按位置匹配**的采样设计，
本项目**不**去构造那种匹配（那会再做一次事后挑选）。

**为什么这条重要**：本文件 §0 与项目里所有「`w` 抬高 `\boxed` marker」的表述，
现在都必须加一个限定 —— `w` 是**组内平均**，而组内符号分裂，
所以它**不是**「抬高 marker 的方向」，它在占多数的 token 上恰恰是**压制**的。
这既是 §4 第 8 条的来源，也可能解释「对齐度反向」为何反复出现又反复消失
（**该解释性假说本项目未检验**，见预登记 §37.4）。
