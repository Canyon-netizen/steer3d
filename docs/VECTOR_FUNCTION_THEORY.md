# Steering 向量功能的因果理论

Steering 向量的功能可以定义为它对模型计算和行为分布实施的干预，而语义解释来自
这种干预与一个可理解的推理过程之间的对应关系。完整解释需要同时回答四个问题：
向量改变哪个变量，变化如何经过下游计算传播，为什么产生指定行为，以及这个解释
在什么条件下可以被识别、预测和推翻。

这里给出一套条件性理论：明确模型、定义、假设、推导、识别条件、误差边界和可检验
预测。它是对微分响应、信息几何和因果抽象的组合与项目化推导，不是已经得到验证的
全新普适定律。它不假设任意向量都有一个唯一的人类概念名称。

文中的“命题”附有推导；“建模假设”需要实验检验。项目当前的关联和局部干预结果
只是这套理论中的部分观测，不能代替其中的语义识别与机制验证。

B 路的最新数值检验见 [BPATH_VECTOR_MECHANISM.md](BPATH_VECTOR_MECHANISM.md)：同向量、
固定前缀扫描把后续 block 传播、RMSNorm 的前传与重缩放、完整 softmax 竞争分开。
它提供了这套理论的定量锚点，同时更正将旧向量的层剖面与 B 向量的静态预测混合后
得出的“下游八层衰减43倍”。原 P9 仍为 1/3，语义程序对应尚未建立。

尤其是，假设 `h=BZ+η` 并不能解释某个现有向量为什么对应 `Z_j`。
如果 `Z` 的语义和 `B` 的生成关系尚未识别，这个假设只是把待解释问题搬进了一个矩阵。
对具体向量的解释必须从模型实际使用的计算出发，建立有独立语义依据的因果路径。

## 任意向量的统一解释形式

通用理论需要为任意向量定义同一种解释对象，并给出语义解释存在的条件。
可以将这个对象定义为：**向量在模型计算上诱导的操作，以及该操作在可解释程序中的对应。**
一个解释允许包含多个功能、上下文条件和无法压缩的细节，不要求所有向量都有单一名称。
下面的统一形式是对干预算子、微分传播和因果抽象的组合推导；它不是已证明真实 LLM
对所有方向都存在简洁语义编码的定理。

### 向量诱导的操作

令 `S` 为注入位置的完整状态，包含当前上下文、计算阶段、残差与必要的缓存。
单个位置的向量注入定义状态操作 `Iᵥ,α(S)`，把指定残差替换为 `h+αv`。
记后续模型执行为 `F`。确定性执行用函数表示，随机生成用转移核表示。
因此，对任意 `v` 都有一个精确定义的被干预计算：

\[
S\ \xrightarrow{I_{v,\alpha}}\ I_{v,\alpha}(S)
\ \xrightarrow{F}\ F(I_{v,\alpha}(S)).
\]

一个函数 `f` 可以读取最终答案、实际计算操作或其他已定义的量。
若读取整个计算过程，应把相应轨迹记录纳入终态 `S_T`。
随机执行时，向量对这个读出的作用由下面的算子统一描述：

\[
(\mathsf K_{v,\alpha}f)(S)
=\mathbb E[f(S_T)\mid S_0=I_{v,\alpha}(S)],
\qquad
\mathsf A_{v,\alpha}=\mathsf K_{v,\alpha}-\mathsf K_0.
\]

这里 `K₀` 使用相同执行策略但不注入。`Aᵥ,α` 可以作用在任意冻结的读出上，
无需先猜测 `v` 是哪一个概念。如果只读答案，它描述答案效应；如果读取已验证的
计算过程，它描述过程效应。读出的语义必须说明，不能根据向量效果临时更换。

**命题 A。** 在有限生成长度下，所有事件的指示函数构成完备读出：
知道 `Aᵥ,α 1_E` 对所有事件 `E` 的值，等价于知道完整结果分布的变化。

**推导。** `Aᵥ,α 1_E=Pᵥ,α(E)-P₀(E)`，事件概率决定分布。
任意有界评分的变化都是对这个有符号分布的积分。
这保证统一对象没有遗漏行为效应；它本身尚未提供简洁的内部机制解释。
只保留正确率或若干 token 概率，是这个完整对象的部分读出。

### 为什么数值方向产生这个作用

对可微的标量读出，令 `f(S)` 表示后续计算得到的值或其期望。
向量诱导一个作用于读出的微分算子：

\[
(\mathcal L_v f)(S)=D_h f(S)[v].
\]

沿注入路径可得精确的有限作用：

\[
f(I_{v,\alpha}(S))-f(S)
=\int_0^\alpha D_h f(I_{v,t}(S))[v]\,dt.
\]

**命题 B。** 对有限、可微的实际计算图，`D_h f[v]` 等于从注入节点到该读出
的所有有向路径的雅可比乘积之和，作用在 `v` 上。

**推导。** 对每个节点应用链式法则；一个节点的输入有多条分支时导数相加，
沿一条路径组合时雅可比相乘。递归展开就得到路径和。
这包括 attention、MLP、normalization 与输出层，也包括同一层内部的绕行路径。
有限剂量需要沿干预路径积分，不能只使用 baseline 的路径权重。
路径分组受计算图表述影响；完整响应不依赖如何分组。

于是，给定 `v` 为什么引起某个作用，数值上由实际权重、当前状态与全部下游
传播共同决定。多点或持续注入应把每个注入节点放入展开计算图；对共同剂量
参数求总导数。硬阈值、greedy 跳变和浮点舍入需要直接处理有限变化。

### 高层语义操作存在的必要且充分条件

设 `τ:S→Z` 把模型状态压缩为一个候选可解释程序的状态。
例如 `Z` 可以包括候选值、约束满足情况、当前所执行的计算步骤和选择规则。
这些变量的含义来自任务和程序操作，不由某个向量的投影来命名。
`τ` 是待识别并检验的映射，不预设已经找到了它。

若向量能被这个程序解释，就应存在高层操作 `Eᵥ,α:Z→Z`，使得：

\[
\boxed{\quad\tau\circ I_{v,\alpha}=E_{v,\alpha}\circ\tau.\quad}
\]

**命题 C。** 在声明域内，对某个干预操作存在上述 `Eᵥ,α`，当且仅当：

\[
\tau(S_1)=\tau(S_2)
\ \Longrightarrow
\tau(I_{v,\alpha}(S_1))=\tau(I_{v,\alpha}(S_2)).
\]

域应包含被比较状态及其干预像。这个条件必须对声称覆盖的每个剂量成立。
它表示：被 `τ` 看作同一个程序状态的两个模型状态，受到同一个向量操作后，
仍产生同一个抽象状态。没有这一性质，单靠 `Z` 无法预测向量的作用。

**必要性证明。** 两个状态的 `τ` 相同，则右侧 `Eᵥ,α(τ(S))` 相同，左侧也必须相同。

**充分性证明。** 对每个 `z`，取任意满足 `τ(S)=z` 的状态，定义
`Eᵥ,α(z)=τ(Iᵥ,α(S))`。条件保证选取不同代表不会改变定义。
这个操作在 `τ` 的像上唯一。

还需要模型执行本身在同一抽象上闭合：

\[
\boxed{\quad\tau\circ F=P\circ\tau.\quad}
\]

确定性情形中，`P` 存在的条件同样是 `τ(S₁)=τ(S₂)` 蕴含
`τ(F(S₁))=τ(F(S₂))`。随机转移则要求它们转移到每个抽象状态类的概率相同；
这是分布上的闭合条件，不能只比较均值。

这两个条件共同给出机制解释：

\[
\tau(F(I_{v,\alpha}(S)))=P(E_{v,\alpha}(\tau(S))).
\]

左边是实际模型加向量后的计算，右边是可解释程序接受对应操作后的计算。
相等时，`v` 的功能就由 `Eᵥ,α` 的操作规则表达，并由 `P` 解释这些规则为何
导致后续推理变化。若最终行为读出可以写作 `b=\bar b\circ\tau`，两条执行路径
对该行为给出相同预测。仅有终点吻合还不能保证每个中间步骤都对应；机制主张
覆盖的每个计算步骤都应检验闭合关系。

因果抽象理论提供了低层干预与高层计算之间对应关系的基础；这里的命题 C
把一个加性向量操作何时能下降到抽象状态空间的条件明确写出。
[Causal Abstractions of Neural Networks](https://arxiv.org/abs/2106.02997)

### 近似解释如何约束预测

真实模型的解释通常只能近似成立。对确定性的分步模型转换，假设在整个声明域
内有一致误差界，且高层转换 `P` 在所选语义距离 `d_Z` 下为 `L` Lipschitz：

\[
d_Z(\tau(I_{v,\alpha}(S)),E_{v,\alpha}(\tau(S)))\le\varepsilon_I,
\qquad
d_Z(\tau(F(S)),P(\tau(S)))\le\varepsilon_F.
\]

**命题 E。** 单次初始注入后执行 `T` 步，模型抽象轨迹与解释程序轨迹的误差满足：

\[
e_T\le L^T\varepsilon_I+
\varepsilon_F\sum_{r=0}^{T-1}L^r.
\]

**推导。** 初始抽象误差至多 `ε_I`。每步用三角不等式和 Lipschitz 条件得到
`e_{t+1}≤ε_F+Le_t`，递推即得。
若行为读出 `b=\bar b\circ\tau`，且 `\bar b` 为 `L_b` Lipschitz，则行为预测误差
至多 `L_b e_T`。读出映射若有近似误差，还需加上相应误差项。

这个界使解释具有预测约束：一段程序能在何种误差下复现 steering 的后果。
它要求所有涉及的状态及其干预像都在域内；有限样本的平均误差不能冒充一致上界。
持续注入会在各步引入额外误差；随机生成需要使用相应的分布距离和转移稳定性条件，
不能直接把某条随机样本轨迹代入上述确定性界。

### 如何构造抽象而不假定已知的语义矩阵

对一个有限、确定性、对所选操作闭合的状态系统，可以给出构造法。
先用独立语义读出 `ψ(S)` 区分必须保留的事实，例如候选是否满足约束。
将 `ψ` 相同的状态放在同一组。然后依次拆分每组：如果其中两个状态经模型
转换或任一允许干预后落入不同组，就把它们分开。重复直到没有组需要拆分。

**命题 D。** 这个过程有限步终止，给出保留 `ψ` 的最粗稳定划分。
以最终组编号作为 `τ(S)`，模型转换与允许干预都满足命题 C 的同类条件。

**推导。** 每次实质拆分增加组数，组数不超过状态数。
任何保留 `ψ` 的稳定划分，都必须区分每轮被拆开的状态；归纳可知最终划分
仍比任意这样的划分更粗。停止时的稳定性保证对应操作定义良好。

这个构造说明抽象不是凭空假定的矩阵。它也没有保证组编号自然对应“谨慎”或
“创造力”：稳定划分可能非常细，转移规则也可能难以压缩成人能理解的程序。
为得到简洁解释，需要用已有意义的程序操作表达状态与转换，并检验表达的误差。
对真实 LLM 的连续状态与巨大计算空间，穷举这个构造通常不可行；有限样本上的
稳定不等于整个域上的稳定，需要条件约束和独立干预检验。

一个简单例子说明拆分为何必要。令 `τ(h)=1[h>0]`，给定干预为 `h←h+1`。
`h=-0.5` 与 `h=-2` 的抽象状态都为 0，干预后却分别变成 1 与 0。
因此，不能在这个两状态程序里把该向量表示为确定的“切换到 1”操作。
抽象必须保留阈值距离等信息，才能预测哪些状态会切换。
这解释了为什么同一向量在同一模型里也可能需要上下文条件。

### 统一理论能保证什么

上述对象对任意向量都适用。它区分三种可以明确给出的结果：

1. `Aᵥ,α` 给出向量对已声明结果和读出的作用。
2. 实际计算图的传播解释这些作用的数值原因。
3. 当抽象条件成立，`Eᵥ,α` 与程序 `P` 给出可预测的语义机制。

任意方向都有前两层的定义；第三层能否简洁表达是需要解决和检验的问题。
把 `τ` 取为完整状态恒等映射总能保持计算，但那没有提供有用的语义压缩。
通用形式与自动得到简洁的人类解释是不同的保证。

没有一个只依赖原始向量数值的跨模型语义规则：在标量状态上，两个模型可以
分别令某行为的概率为 `σ(h)` 和 `σ(-h)`；同一个 `v=+1` 对它们作用相反。
即使固定模型 `P(行为)=σ(h²)`，同一个正向向量在正、负 `h` 附近的局部作用
也相反。因此，完整解释对象必须包含模型、注入位置、上下文域与策略。

得到单一语义功能的条件可以进一步明确。如果 `Eᵥ,α` 在声明域内遵循一个固定
程序操作，例如只修改某决策阈值，而其他可以独立变化的程序变量保持对应，
那么该操作可用于命名功能。若它同时修改多个变量，解释就应包含这些操作。
若不同抽象程序在所有允许干预上仍无法区分，理论只能识别其解释等价类。

因此，任意向量的通用解释格式是：**它在这些条件下对可解释计算施加哪些操作，
这些操作经哪些转换导致哪些结果，以及这个对应在哪些地方失效。**
后面的局部响应、功能几何、参考方向分解和中介检验，是这一统一形式的可计算部分。

## 为什么可以把一个功能归给给定向量

需要区分三个不同的因果问题：向量为什么被提取出来，它为什么产生某种数值作用，
以及这种数值作用为什么实现某种推理功能。前两项不自动回答第三项。

### 提取规则解释的是向量来源

仓库里的 `caution` 是“自检标记 token 状态的均值减去普通 token 状态的均值”。
这些标记根据 token 文本与正则识别。`confidence_up` 来自低熵与高熵状态的差；
`reasoning_deep` 来自后期与早期状态的差；`creativity` 来自 think 块内外状态的差。
这些规则为向量提供了名称，但没有识别验证、推理深度或创造力的内部计算。

对差均值向量 `v=μ₊−μ₋`，有恒等式：

\[
v^\top\mu_+-v^\top\mu_-=\|\mu_+-\mu_-\|^2.
\]

所以在抽取数据上投影分离这些标签，部分是构造本身保证的。
它回答“为什么这个方向能区分这两组状态”，没有回答“为什么注入它会执行验证”。
CAA 使用对比状态构造干预方向；该来源本身也不是完整的内部机制证明。
[Steering Llama 2 via Contrastive Activation Addition](https://arxiv.org/abs/2312.06681)

### 实际读入向量的计算解释它为何有效

考虑一个语义已被独立确认的验证门控。假设门控的实际前向计算为：

\[
g(h)=\operatorname{ReLU}(a^\top h-\tau),
\qquad s(h)=\kappa g(h)+c(h),
\]

其中 `s` 是执行验证分支相对于直接输出分支的 log odds，`κ>0`；
`c` 汇集其他计算路径。验证分支必须实际执行候选解与原约束的比较，
不能只因为它输出 `Wait` 就被命名为验证。

在门控保持激活的剂量区间，注入给定向量后：

\[
\Delta s=\alpha\kappa a^\top v+
         c(h+\alpha v)-c(h).
\]

若其他路径沿 `v` 的变化足够小，`a^Tv>0` 就增加验证分支的 odds。
这给出了“为什么这个向量促进验证”的原因：模型的实际读入权重 `a` 响应该方向，
门控增加验证计算的选择概率，验证分支再影响解题行为。
同样长度、但满足 `a^Tv=0` 的方向不会通过这个门控产生一阶作用。

如果向量同时改变 `c`，或门控跨过阈值，就必须把这些变化纳入解释。
若 `g` 的语义没有被确认，上式只能解释门控或输出 odds 的变化，不能解释验证。
该例子是已知计算图中的可计算因果说明，不是对 Qwen 已识别电路的描述。

真实 Transformer 的读入更复杂。比如一个 SwiGLU 单元在其输入 `h` 上计算：

\[
m_j(h)=\operatorname{SiLU}(a_j^\top N(h))\,b_j^\top N(h).
\]

令 `u_j=a_j^T N(h)`、`w_j=b_j^T N(h)`，则它读入局部方向 `v` 的响应是：

\[
\partial_\alpha m_j(h+\alpha v)|_0
=\operatorname{SiLU}'(u_j)w_j\,a_j^\top DN(h)v
+\operatorname{SiLU}(u_j)b_j^\top DN(h)v.
\]

这些项由实际权重、当前状态和 normalization 决定。如果向量注入在 attention 之前，
还需把 attention 对状态的变化传播到这个输入。被影响的单元通过 down projection
和后续层改变输出。单元可能有多种功能，不能单靠大导数赋予语义标签。

因此，向量功能的微观原因是它激发、抑制或重组了哪些已学会的计算路径。
向量中的原始数值依赖模型学到的坐标系；相同功能换坐标后可以对应另一组数值。

### 语义依据必须来自能够区分替代原因的计算

给“验证门控”这一语义需要区分至少以下解释：

| 候选解释 | 需要预测的事实 | 单独增加自检词能否确认 |
|---|---|---|
| 选择执行约束验证 | 出现实际约束比较，错误候选能被有效纠正，正确候选不被随意改错 | 不能 |
| 改变自检表达风格 | 修订词增多，实际验证操作可以不变 | 可以支持表达变化，不能确认验证 |
| 改变生成长度 | 输出更长，额外内容未必是验证 | 不能 |
| 改变预测集中程度 | token 熵改变，候选答案可以仍然错误 | 不能 |

对于已有 AIME 推理，可以用正确与错误候选、是否已完成约束验证、不同表达形式
构建相互区分的任务。正确性与验证步骤必须用数学约束或冻结的判据核查。
参考状态要保留 token 位置、题目内容、难度与格式的匹配条件；
仅改变 prompt 中“请检查”的词语不能保证内部发生了对应计算。

计算路径与语义的对应，需要同时符合这两类事实：路径随实际验证问题而变化，
而且改变该路径会以预期方式改变验证行为。还要检验其他候选原因是否同样解释结果。
没有可区分预测的两个语义假设，不能被同一组实验唯一识别。

### 原因解释应能预测移除和替代

若主张向量通过一组中介计算 `M` 促进验证，解释应预测：恢复这组计算到 baseline
会减少向量的目标作用；用相应中介变化替代原向量，应重现解释所预测的部分作用。
两种实验都需要检验替换自身的影响和绕行路径。

梯度可以定位候选路径。若一组节点构成覆盖所有相关路径的可微计算截面，则链式法则为：

\[
\partial_\alpha s=
\sum_k\frac{\partial s}{\partial f_k}
       \frac{\partial f_k}{\partial\alpha}.
\]

若截面不完整，必须保留其他路径；把不同层的梯度贡献直接相加可能重复计数。
如果节点来自 SAE 或其他替代模型，重建误差也需要计入，并在原模型中验证干预。
Circuit Tracing 同样把归因图作为机制假设，使用实际模型干预检验其预测。
[Circuit Tracing](https://transformer-circuits.pub/2025/attribution-graphs/methods.html)

这条逻辑链才构成具体的功能归属：

`给定向量 → 实际读入权重和状态变化 → 有独立语义依据的计算路径 → 推理行为`。

目前项目对 `caution` 没有建立这条完整路径。已经测得的某个 token 概率变化不能填补
中间的语义依据，因此现阶段不能断言它是一个验证功能向量。

## 解释对象的定义

固定模型参数、精度、tokenizer 和推理配置。令 `x` 表示问题与已生成的 token 前缀，
`S` 表示完整计算状态，包含残差、其他位置的激活及 KV cache。
微分推导针对实数计算图的光滑模型；浮点和量化误差需要单独通过差分步长与精度检验。
在指定层、指定输入或输出侧、指定位置的残差 `h∈R^d` 上施加干预：

\[
I_{v,\alpha}: h\leftarrow h+\alpha v.
\]

`v` 的范数与 `alpha` 必须共同保留；若先把 `v` 单位化，`alpha` 就是绝对注入量。
若使用相对强度，令 `alpha=s·c(x)`，其中 `c(x)` 是 baseline 的实测范数；
针对相对旋钮 `s` 的导数会额外乘以 `c(x)`。

注入范围还需指定策略 `π`：只注入一个位置、每个生成步注入、只在某些事件注入，
或把前缀各位置都注入。这些是不同的干预，不能共享一个未注明范围的解释。
全局理论用 `q_{αv,π}(Y|x)` 表示干预后完整续写的分布。

一个向量解释的基本对象因此是：

\[
\mathcal E=(\theta,\text{site},v,\pi,\mathcal D,\mathcal A,\mathcal B,\mathcal M).
\]

`D` 是声明适用的上下文分布，`A` 是剂量区间，`B` 是行为指标，`M` 是候选
高层推理模型。缺少后两项时，可以解释数值响应，但还没有确定它的人类语义。

## 为什么 hidden states 不能单独决定功能

**命题一。** 自然运行中的 hidden states 和投影相关，通常不足以识别一个向量的
干预功能。即使两个模型在全部已观测状态上输出相同，它们也可能对同一干预给出相反响应。

**反例。** 假设自然数据中的状态都满足 `h₁=0`。构造两个下游 logit 函数：

\[
z_+(h)=(h_1,0),\qquad z_-(h)=(-h_1,0).
\]

自然运行中，它们都有相同状态和相同输出概率。注入 `v=(1,0)` 后，一个提升第一个
token 的概率，另一个降低它。观测不能识别未被自然数据探索的方向上的响应。
有限数据上也可以构造在所有观测点取相同值、但具有不同方向导数的函数。
若精确的下游函数已经确定，或者具有足够覆盖和正则条件来确定它的局部导数，
上述未识别问题可以缩小；这里并不否认在更强信息条件下的可识别性。

因此，只有 `.npy` 和状态轨迹时，可靠结果应是候选关联；获得下游模型或真实干预
响应后，才能识别因果作用。即使所有输出响应都已知，人类概念如何命名仍需外部语义定义。
这个限制来自信息不足，不能通过更漂亮的聚类或更多向量名称消除。

## 局部功能的传播方程

在固定前缀 `x` 上，把剩余下游计算写作 `z_x(h)`，输出概率为 `p_x=softmax(z_x)`。
这里的函数包含后续 attention、MLP、normalization 和 unembedding。
令 `J_z(x)=∂z_x/∂h`，定义向量的局部输出功能：

\[
r_v(x)=\left.\frac{\partial\log p_x(h+\alpha v)}{\partial\alpha}\right|_{0}
       =(I-\mathbf1p_x^\top)J_z(x)v.
\]

这是一个词表维度的响应，而不是一个概念名称。`r_{v,i}>0` 表示在足够小的正向干预
下，第 `i` 个 token 的概率增加。减去 `p_x^T J_zv` 去除了共同 logit 平移；
共同平移不改变模型概率。

**命题二。** 局部功能由下游计算的雅可比作用在 `v` 上决定。两向量是否有相同
局部功能，需要比较 `r_v`，不能仅比较它们在残差空间中的欧氏余弦。

**推导。** 对 `log p_i=z_i−logsumexp(z)` 求导即得上式；再对下游复合函数应用
链式法则。若用整个残差张量表示中间状态，`J_z` 包含从指定注入位置到读出位置
的完整传播。直接计算 `W_head v` 等价于忽略这些传播项，通常不能预测真实作用。

若某个 log 概率在剂量区间内二阶可微，并且沿干预路径的 Hessian 算子范数不超过 `M`，
则 Taylor 余项满足：

\[
\left|\Delta\log p_i-\alpha r_{v,i}\right|
\le \tfrac12\alpha^2M\|v\|^2.
\]

这是局部理论的剂量边界。它不产生一个跨模型、跨层通用的“安全强度 0.2”。
若需要大剂量的解释，应研究 `r_v(x,α)` 随剂量的变化，而不能持续外推零点导数。

## 从输出响应定义推理功能

行为指标必须独立于向量提取过程定义。比如“检查候选解”可以操作化为：
对候选解执行原约束验证，并根据验证结果保留或修订答案。
`Wait` 的出现、输出长度和后期 token 位置不能独立构成这个定义。

可以采用如下指标，它们分别回答不同问题：

| 指标 | 定义对象 | 可以支持的解释 |
|---|---|---|
| 验证操作发生率 | 后续是否执行可核查的代入或约束验证 | 是否改变了显式验证行为 |
| 错误候选修订率 | 在错误候选下是否修正最终结论 | 是否促进有效修订 |
| 正确候选误改率 | 在正确候选下是否错误修改结论 | 是否引入无效怀疑 |
| 最终正确率 | 答案是否满足独立题目判据 | 是否影响任务结果 |
| token 熵 | 当前预测分布的不确定性 | 是否改变预测集中程度 |
| 修订标记率 | 是否输出定义好的词法标记 | 是否改变表达形式 |

对能够作为续写函数的判据，令 `b_j(Y,x)` 为冻结的评分规则，定义精确功能效应：

\[
F_{v,j}(x,\alpha)=
\mathbb E_{q_{\alpha v,\pi}}[b_j(Y,x)]
-\mathbb E_{q_{0,\pi}}[b_j(Y,x)].
\]

`F_v` 给出“向什么方向推理”的操作性答案：它增加或减少哪些行为、幅度多少、
在哪些上下文和剂量成立。自然状态上的相关性不是这个量。

表中的 token 熵是概率分布的泛函，不是某个固定 token 评分的期望。
其有限效应应直接比较 `H(p_α)−H(p_0)`，局部导数为
`∂H/∂α=−sum_i p_i r_{v,i} log p_i`。
不能把分布熵与冻结的行为评分混为一谈。

**命题三。** 在有限生成长度、正 softmax 概率、固定策略和可交换求导与求和的条件下，
完整生成的行为响应满足：

\[
\left.\partial_\alpha\mathbb E_{q_{\alpha v,\pi}}[b_j]\right|_0
=\mathbb E_{q_0}[(b_j-\mathbb E_{q_0}b_j)S_v(Y)],
\qquad S_v(Y)=\left.\partial_\alpha\log q_{\alpha v,\pi}(Y|x)\right|_0.
\]

**推导。** 用 `∂q=q∂log q` 展开期望，并利用 `E_q[S_v]=0`。
对自回归生成，`S_v` 等于每步条件 log 概率的总导数之和。总导数必须包含干预
通过 KV cache、数值状态与指定策略向未来传播的影响。

这说明：当前 token 的变化怎样影响完整行为，取决于它与后续行为的统计耦合。
提高一个自检标记的概率，不自动意味着提高有效修订率。
greedy 输出在 argmax 边界可以跳变，上述光滑推导针对概率分布；
对 greedy 行为应另报有限干预结果。
依赖状态阈值的硬门控也需要检查是否跨越阈值，不能自动套用光滑展开。

## 读出方向和控制方向的区别

假设在某个局部区域内，可解释的高层变量 `Z` 与残差近似满足：

\[
h=BZ+\eta.
\]

这是需要验证的建模假设，不能由“线性探针效果不错”直接推出。
若暂时忽略噪声，且 `B` 可逆，那么读取第 `j` 个变量的 covector 是
`w_j=B^{-T}e_j`，而只改变这个变量的写入方向是 `d_j=Be_j`。
它们一般不相同。读出是一个线性函数，控制是对状态的干预。

在更一般的局部描述中，固定干预策略后，令 `C(x)` 的每一行是行为期望对共有
加性干预参数在零点的梯度。单点干预时它就是对该残差的梯度；多点干预时它包含
各注入点及状态传播的总响应。于是：

\[
\Delta\mathbb E[b\mid x]\approx\alpha C(x)v.
\]

如果想得到指定高层干预的效应模式 `a_j`，需要解 `Cv=a_j`。
若 `a_j` 不在 `C` 的列空间中，这个干预不能由该层一个加性向量局部实现。
若解不唯一，功能约束只能确定一个等价类，还要说明如何选择代表向量。

给定正定代价矩阵 `M`，且 `C` 满行秩，最小代价解为：

\[
v_j^*=M^{-1}C^\top(CM^{-1}C^\top)^{-1}a_j,
\qquad \min_v\tfrac12v^\top Mv\ \text{s.t. }Cv=a_j.
\]

**推导。** 对约束优化写出 Lagrangian，驻点满足 `Mv=C^Tλ`；代回约束求 `λ`。
这个公式区分了“哪个方向能读出属性”和“哪个方向能控制属性”。
如果指标彼此因果关联，`a_j` 应包含高层模型预测的全部后果；
不能要求一个变量改变后，其所有下游行为都保持不变。

Park 等人对测量表示和干预表示的区分，以及在特定可分离条件下连接二者的
非欧氏几何，提供了相关理论基础。这里的中间层响应与控制公式是按项目模型展开的
推导，不是直接套用其最终表示空间的定理。
[The Linear Representation Hypothesis and the Geometry of Large Language Models](https://arxiv.org/abs/2311.03658)

## 功能的几何和可识别性

在声明的上下文分布 `D` 上定义局部输出代价：

\[
G=\mathbb E_{x\sim\mathcal D}
[J_z(x)^\top(\operatorname{diag}p_x-p_xp_x^\top)J_z(x)].
\]

等价地，令 `J_logp=(I−1p^T)J_z`，则 `G=E[J_logp^T diag(p) J_logp]`。
这是下一 token 分布的 Fisher 度量拉回注入空间后的矩阵。
它依据声明的数据分布，通常半正定；不能把它当作唯一普适的语义内积。

**命题四。** 在光滑局部区域，平均 KL 具有展开：

\[
\mathbb E_x\operatorname{KL}(p_{0,x}\Vert p_{\alpha v,x})
=\tfrac12\alpha^2v^\top Gv+o(\alpha^2).
\]

**推导。** KL 在零干预处的一阶导数为零；二阶项为概率模型的 Fisher 信息。
代入 `∂log p/∂α=J_logp v` 得到上式。

所以同范数向量可以产生完全不同的输出代价；其差别来自 `G` 对不同方向的敏感性。
同范数随机对照回答“同样的残差注入量是否有特异作用”；同 KL 对照回答
“同样的总体输出变化是否更集中在目标功能”。两类对照各自需要说明匹配规则。

**命题五。** 两个方向在该数据分布上的一阶概率功能相同，当且仅当：

\[
(v-w)^\top G(v-w)=0.
\]

**推导。** 左式是 `E_x sum_i p_i[r_{v,i}−r_{w,i}]²`。
各项非负，softmax 概率为正，因此其为零等价于响应几乎处处相同。
可识别对象是一阶功能等价类 `R^d/ker(G)`。
落在核中的方向可能有二阶作用，也可能在另一数据分布上有作用，不能宣称永远无功能。

如果只观察少数行为指标，那么 `C` 的核一般更大：
“没有改变已测指标”不等于“没有改变模型”。
另一方面，如果只测了 `K` 个方向组成的矩阵 `V`，看到 `CV`，且 `rank(V)<d`，
则任何满足 `UV=0` 的非零矩阵 `U` 都让 `C+U` 给出相同观测。
一次 ±v 实验可以识别指定方向的响应，不能识别整个控制算子。

**坐标不变性。** 重新表示残差 `h'=Ah` 时，`v'=Av`，读出 covector 变成
`w'=A^{-T}w`，而 `G'=A^{-T}GA^{-1}`。
因此 `w'^T v'=w^T v` 和 `v'^T G'v'=v^T Gv` 不变。
原始欧氏余弦在一般可逆变换下没有这个性质。

## 把任意向量分解为已验证的功能

准备由独立干预与语义验证得到的参考控制方向 `D=[d₁,…,d_k]`。
它们不能仅靠 CAA 名称或 SAE 标签就被当作已验证功能。
用上面的概率响应几何定义最小残余分解：

\[
v=D\beta+r,\qquad
\beta=(D^\top GD)^{-1}D^\top Gv.
\]

**命题六。** 如果 `D^TGD` 正定，这个分解系数唯一，并满足 `D^TGr=0`。
它是在声明域内，参考方向的功能响应对目标向量功能响应的最小二乘解释。
若 `D^TGD` 奇异，某些参考方向功能不可区分，系数解释不唯一；
用伪逆选一个数值解不会消除这种不唯一性。

当 `v^TGv>0` 时，功能覆盖率可定义为：

\[
\operatorname{coverage}(v)=1-\frac{r^\top Gr}{v^\top Gv}.
\]

它描述已验证参考功能解释了多少局部输出响应能量，不是“解释了多少模型思维”。
未覆盖残余应保留为未知；不能把它自动命名为创造力、深推理或噪声。
还需报告 Gram 矩阵的条件数，因为接近奇异时，系数会对测量误差非常敏感。

实际不必存储整个 `d×d` 的 `G`。对每个参考方向测完整响应 `r_{d_j}`，
就可以计算 `D^TGD` 的第 `i,j` 项为 `E_x sum_t p_t r_{d_i,t}r_{d_j,t}`，
并计算 `D^TGv`。只保存 top-k token 会丢失这项识别所需的信息。

这产生一种可核验的解释：“在指定题型和剂量附近，该向量相当于这些参考控制
方向的组合，剩余功能响应占多少。”系数的意义依赖参考功能的定义与校准单位。

## 一个可以明确算出功能的例子

在理想化的二维系统中，定义 `z₁` 为验证候选解的倾向，`z₂` 为压缩答案的倾向，
并假设它们通过如下已知映射进入残差：

\[
h=Bz,\quad B=\begin{pmatrix}1&1\\0&1\end{pmatrix},
\quad z=B^{-1}h=\begin{pmatrix}h_1-h_2\\h_2\end{pmatrix}.
\]

读取验证倾向的探针是 `(1,−1)`。直接把这个探针当作 steering vector 加进去时：

\[
\Delta z=B^{-1}(1,-1)^\top=(2,-1)^\top.
\]

它同时增加验证、减少压缩。只改变验证的方向应为 `d₁=(1,0)`；
只改变压缩的方向为 `d₂=(1,1)`。
给定未知向量 `v=(2,1)`，可以明确推导：

\[
v=d_1+d_2,\qquad \Delta z=(1,1)^\top.
\]

这里“向量具有两种功能”来自可识别的生成映射与干预关系，不是来自向量余弦。
若用高层状态的欧氏变化作为成本，拉回残差后的度量为
`G_z=B^{-T}B^{-1}`，两个写入方向在这个度量下正交。
这是高层状态成本的例子，不是对真实 Qwen Fisher 矩阵的计算。

真实模型要得到同样强度的解释，必须识别和验证相应的高层变量、映射和下游作用。
这个例子给出理论在假设成立时能产出的明确答案，也指出未知量在哪里。

## 为什么差均值不自动得到一个纯功能

继续使用局部模型 `h=BZ+η`。根据标签分正负组的 CAA 向量满足：

\[
v_{\rm CAA}=B\big(\mathbb E[Z|+] - \mathbb E[Z|-]\big)
          +\mathbb E[\eta|+] - \mathbb E[\eta|-].
\]

只有当两组的其他高层变量和噪声均值得到适当匹配时，差均值才可能主要隔离目标
变量的写入方向。按高低熵分组，也可能同时改变数字出现率、阶段、难度与表达形式；
按早晚位置分组，则直接选择了进度状态，不能把结果自动解释为推理深度。

Jiang 等人在简化潜变量模型下推导了线性表示为何可能由训练目标和优化偏置产生。
这支持研究上述假设，但不证明任意真实模型、层和人类推理变量都服从这个生成模型。
[On the Origins of Linear Representations in Large Language Models](https://arxiv.org/abs/2403.03867)

## 如何把行为功能提升为机制解释

行为响应仍可能有多个内部原因。要解释“这个向量让模型更愿意检查候选解”，
需要提出一个明确的高层因果模型 `M`，例如：

`读取约束 → 形成候选解 → 验证候选解 → 根据验证结果保留或修订 → 输出答案`。

令 `τ:S→Z` 把低层计算状态对应到这些高层变量。高层模型还需定义变量的转换
以及可干预的节点。对候选 steering 功能，定义高层干预 `i_{j,g(α)}`。
机制解释至少要求下面两个对应关系在声明域内近似成立：

\[
\tau\circ I_{v,\alpha}\approx i_{j,g(\alpha)}\circ\tau,
\]

\[
\tau\circ F_{\rm low}^{I_{v,\alpha}}
\approx F_{\rm high}^{i_{j,g(\alpha)}}\circ\tau.
\]

第一式说干预改变了哪个高层变量；第二式说后续转换与行为是否按同一个高层模型
预测的方式改变。随机生成时，两式比较相应分布，而不是要求每次采样完全相同。
仅训练一个能读出标签的 `τ` 不够：要验证干预也具有对应的因果作用。

这是因果抽象的基本思想。Geiger 等人用 interchange interventions 检验神经表示
是否具有与高层变量对应的因果性质；本项目可以把它用于候选推理步骤的验证。
[Causal Abstractions of Neural Networks](https://arxiv.org/abs/2106.02997)

语义识别可以按以下逻辑进行：

1. 独立定义验证行为与高层变量，冻结语义映射，不根据 steering 结果重新贴标签。
2. 在正确与错误候选、不同难度和不同措辞的题目上检验高层模型的可区分预测。
3. 对疑似中介状态执行替换或 interchange，观察下游是否服从对应的高层干预。
4. steering 后恢复该中介到 baseline，检验目标效果是否消失；再加入中介干预，
   检验是否能够恢复相应效果，并检查替换本身的对照。
5. 在独立题目上验证两条对应关系，并报告误差、失败条件和冗余路径。

恢复实验可以检验某个中介对指定 steering 效果的必要性；它不证明该中介对所有
自然推理都必要。存在交互或冗余时，一个恢复量也不构成唯一的机制贡献比例。
高层模型之间若在全部可实施干预上仍无法区分，应保留多个解释。

## 一个向量获得明确功能名称的条件

“促进验证”这个名称需要一个声明域上的预测，而不是一次正向变化。
可以预先规定目标效应阈值 `μ`、容许失败比例 `δ`、剂量区间与非目标容许误差。
在光滑局部区域，一个稳定的目标响应要求：

\[
\Pr_{x\sim\mathcal D}[C_j(x)v\ge\mu]\ge1-\delta.
\]

有限剂量则直接对 `F_{v,j}(x,α)` 检验相应约束，并检验高层模型预测的其他后果。
所谓选择性，是保持可独立变化的非目标变量，而不是压制目标变量应有的所有下游作用。
阈值的单位和用途应在取数之前定义，不存在通用的一组数值阈值。

一个充分具体的最终解释应包含：

“在域 `D`、注入侧与位置 `site`、策略 `π`、剂量区间 `A` 内，向量以 `g(α)` 的幅度
改变高层变量 `Z_j`；其作用通过这些已检验中介传播，导致这些行为效应。
该对应关系的误差与失败比例为这些值，参考功能分解尚未覆盖这些响应。”

若只能识别 `F_v`，就报告功能效应；若还能验证 `τ` 与干预对应关系，才报告机制。
若响应跨上下文翻转，应报告条件功能 `F_v(x,α)` 或寻找经独立验证的适用子域，
不能用全局平均掩盖翻转。

## 理论的可证伪预测

| 理论条件 | 推导出的预测 | 怎样发现条件不成立 |
|---|---|---|
| 小剂量光滑区域 | `r_{av+bw}=a r_v+b r_w`，有限变化近似线性 | 实测组合效应明显超出 Taylor 和数值误差 |
| 稳定单一功能方向 | 声明域内目标效应符号与范围稳定 | 独立题目中频繁反号或依赖未声明条件 |
| 已验证参考功能覆盖 | `r_v≈sum_j β_j r_{d_j}` | 新上下文上的残余响应很大 |
| 读出与高层变量对应 | 读出在独立变化与干预下仍对应同一变量 | 读出仅利用难度、位置或表达标记 |
| 中介解释成立 | 恢复与互换产生高层模型预测的行为 | 恢复不消除效果，互换效果违反模型预测 |
| 功能解释可识别 | 参考响应的 Gram 矩阵具有足够数值秩 | 多个参考方向产生无法区分的响应 |

局部加性是微分的性质；它不证明一个向量就是单一概念。
通过这些预测检验，理论才开始解释和约束实验，而不只是事后描述结果。

## 需要更正的旧理论表述

现有 `STEERING_INTERPRETABILITY_FRAMEWORK.md` 的证据分级可以继续作为实验记录，
但下面两点不能作为理论前提：

第一，范数代价不严格独立于方向。令 `c=cos(h,v)`、`||v||=1`、
`a=α/||h||`，正确展开为：

\[
\frac{\|h+\alpha v\|}{\|h\|}
=\sqrt{1+2ac+a^2}
=1+ac+\tfrac12a^2(1-c^2)+O(a^3).
\]

`c` 依赖向量方向；只有 `c≈0` 时，二阶范数项才近似为 `a²/2`。
输出 KL 的代价还依赖下游 `G`，更不能只由强度决定。

第二，自然状态沿一个方向的投影与标签相关，最多支持关联或可读性，
不构成因果必要性。必要性需要定义被移除或恢复的变量及干预，再检查行为结果。

这些更正改变了理论前提，但不会自动更改旧文件中的实验数值；旧产物应按各自
采集与检验口径重新解释。
